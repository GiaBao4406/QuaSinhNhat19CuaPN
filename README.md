# 🎂 Birthday Gift Website – Phương Nhung

Đây là một **website nhỏ được tạo ra như món quà sinh nhật dành cho Phương Nhung**.
Trang web hiển thị lời chúc sinh nhật, hiệu ứng pháo hoa, nhạc chúc mừng và một video kỷ niệm.

Project được xây dựng bằng **HTML, CSS và JavaScript** nhằm tạo một trải nghiệm chúc mừng sinh nhật đơn giản nhưng ý nghĩa.

---

# 🎉 Nội dung website

Website bao gồm các thành phần chính:

### 1️⃣ Hiệu ứng pháo hoa

Khi mở trang web, nền sẽ hiển thị **hiệu ứng pháo hoa** tạo không khí sinh nhật.

---

### 2️⃣ Hiệu ứng chữ chạy (Typing Effect)

Dòng chữ tiêu đề sẽ xuất hiện **từng ký tự một** để tạo hiệu ứng chúc mừng sinh nhật.

---

### 3️⃣ Lời chúc sinh nhật

Sau khi hiệu ứng chữ hoàn thành, trang web sẽ hiển thị lời chúc:

> Sinh nhật vui vẻ nhaaa !
> Chúc Phương Nhung sinh nhật vui vẻ, không muộn phiền túi nhiều tiền ❤️

---

### 4️⃣ Nút nhận quà

Người dùng có thể bấm nút:

```
Bấm để nhận Quà !
```

Sau đó trang web sẽ hiển thị nội dung quà.

---

### 5️⃣ Video kỷ niệm

Trang web sẽ mở một **video kỷ niệm** dành riêng cho Phương Nhung.

---

### 6️⃣ Nhạc sinh nhật

Website tự động phát **bài hát Happy Birthday** để tăng không khí sinh nhật.

---

# ▶️ Cách chạy website

Đây là **website tĩnh**, không cần server.

### Cách 1 (đơn giản)

Mở file:

```id="p2bq93"
index.html
```

bằng trình duyệt:

* Google Chrome
* Microsoft Edge
* Firefox

---

### Cách 2 (khuyến khích)

Nếu dùng **VS Code**:

1. Cài extension **Live Server**
2. Chuột phải vào `index.html`
3. Chọn:

```id="4t4p8b"
Open with Live Server
```
